IMPORTANT SECURITY NOTE
-----------------------
The Firebase web configuration contains a Firebase API key. Firebase web API keys
are commonly included in client-side applications; the key itself should not be
treated as a secret. Security depends on Firebase Authentication, authorized
domains, Firestore/Storage security rules, and other Firebase configuration.

Do not expose:
- admin passwords
- service-account credentials
- private API secrets
- server-side credentials
