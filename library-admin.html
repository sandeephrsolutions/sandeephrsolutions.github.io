Setup checklist

  1. In Firebase Console, enable Email/Password Authentication.
  2. Create one admin user; do not enable public account creation.
  3. Deploy the provided Firestore rules from firestore.rules.learning-library.txt after merging with existing site rules.
  4. Confirm firebase-config.js matches your project and add the admin UID to the allowlist in the rules.
  5. Use public links first. Configure a secure Cloudflare R2 upload Worker separately before enabling direct upload.
